# Orpheus Dashboard

## Product Overview

**Orpheus** is a Jellyfin-compatible media server with a focus on beautiful UX, zero-friction setup, and family-first design. The admin dashboard (`/admin`) is the primary configuration interface.

## Target Audience

- **Primary**: Families and home media managers who want a Netflix-like experience from their self-hosted library
- **Secondary**: Self-hosting enthusiasts who value craft and thoughtful defaults over endless configuration

## Core Value Proposition

> "Your media, beautifully organized, effortlessly accessible."

Orpheus bakes in metadata addons (TMDB, Stremio), intelligent catalog management, and a dashboard that feels like a product — not an admin panel.

## Key Differentiators

| vs. Jellyfin/Remux | Orpheus |
|---------------------|---------|
| Admin panel for sysadmins | Dashboard for home media managers |
| Addons = advanced feature | TMDB built-in, catalogs = first-class |
| "Configure everything" | "Sensible defaults, adjust if needed" |
| Technical audience | Family audience |
| Utilitarian aesthetic | Crafted, warm, distinctive |

## Brand Personality

- **Archetype**: Caregiver + Everyman (The Thoughtful Host)
- **Voice**: Warm, confident, quietly expert — like a knowledgeable friend helping you set up your living room
- **Tone**: Calm, reassuring, never condescending. Technical when needed, invisible when not.

## Primary User Flows

1. **First-run setup** — Wizard: Server name → Admin account → Done
2. **Add sources** — TMDB built-in, Stremio catalogs, local folders
3. **Manage library** — Virtual folders, collections, metadata refresh
4. **Configure streaming** — Transcoding, hardware acceleration, quality
5. **Branding** — Custom CSS/JS, login disclaimer
6. **Monitor** — Activity, sessions, tasks, logs

## Success Metrics

- Time from install to first playing media < 5 minutes
- Zero-config metadata working for 90% of libraries
- Dashboard task completion rate > 80% without docs
